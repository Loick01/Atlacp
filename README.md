# Atlacp (WIP)

### How to compile

```bash
# Run these commands from the root directory
mkdir build
cd build
cmake ..
make
./atlacp # Run from the main menu
./atlacp 0 # Same as ./atlacp
./atlacp 1 # Run the world map
./atlacp 2 # Run the battle mode
./atlacp 3 # Run the map editor
```
